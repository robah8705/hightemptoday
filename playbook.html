WHAT'S INSIDE — THE 7-PART SYSTEM

A listicle tour of the playbook, in the order your agent runs it every day.
1

Pick & bracket selection

How the agent reads forecasts and live station data, demands a tight forecast spread, and only takes the bracket the forecast actually supports — modal or adjacent, nothing else.

2

Build multi-leg slates

One position per city, spread across time zones — East Coast, Central/Mountain, West Coast — so the whole day isn't riding on a single city's peak.

3

Hedge & mitigate risk

Hard per-ticket caps, a total daily budget, an uncommitted reserve, and a walk-away loss limit — set before the first order, not after a bad hour.

4

Size positions with discipline

Entry only inside a set price band. If the ask runs more than a few cents above the plan, the agent skips the leg. No chasing — ever.

5

Diligence before every trade

The pre-trade checklist: forecast source, station, bracket, price, fees, and cap — all stated up front and confirmed before a single order is placed.

6

Cash out on take-profit rules

A standing monitor checks open positions on a schedule and plans the exit when profit passes +50% — so a peak that comes and goes midday isn't money left on the table.

7

Streamline it into a daily system

Every trade goes in a running ledger the day it happens, with a full end-of-week review — the habit that turns daily trading into data you can actually improve.
